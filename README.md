# 余额小窗

桌面置顶小窗，显示 DeepSeek 余额、今日已用与峰谷时段，带一个会呼吸、会晃、会回应鼠标的桌宠。

纯 Windows 自带组件（PowerShell 5.1 + WPF）实现，**零第三方依赖、无需安装、无需编译**。

## 快速开始

1. 把整个文件夹放到任意位置（不要求在 C 盘）
2. 复制 `api-key.txt.example` → 改名为 `api-key.txt`，把占位符换成你的 DeepSeek key
   （不给 key 也能跑，只是会退回读本地账本的模式）
3. 双击 `start-silent.vbs` 启动（无黑框）
4. 想放桌面：右键 `start-silent.vbs` → 发送到 → 桌面快捷方式，再把图标换成 `pet.ico`

> 仓库里**不包含**任何真实密钥。`api-key.txt` / `third-key.txt` 已被 `.gitignore` 排除。

## 数据从哪来

两条路，**联网优先**：

### 1. 联网查（推荐，DSH 不开也能用）

去 [platform.deepseek.com](https://platform.deepseek.com/api_keys) 申请一个 API key（`sk-` 开头），
存成小窗目录下的 `api-key.txt`（**一行明文，不要引号**），重启小窗即生效。

- 接口：`GET https://api.deepseek.com/user/balance`，鉴权 `Authorization: Bearer <key>`
- 每 **60 秒**查一次（不会每 3 秒狂刷）
- 返回里除了总余额还带「赠送 / 充值」两项，鼠标停在金额上能看到
- 在设置里用右键菜单 → 联网查余额 可以随时关掉

> ⚠️ **不要**拿 DSH 凭据库里的 `deepseek-account-platform` token 去调这个接口 ——
> 那是 DSH 的服务会话令牌，不是平台 API key，实测会 **401**。必须是 `sk-` 开头的那个。
>
> `api-key.txt` 是明文。安装脚本会把它的权限收紧到「只有你自己」。
> 不想留明文就删掉它，小窗会自动退回本地账本。

key 的查找顺序：环境变量 `DEEPSEEK_API_KEY` → 小窗目录 `api-key.txt` → `<DSH_HOME>\.env`。

### 2. 本地账本（回退）

没配 key、或联网失败时，读 **DSH 的 `dsh-whale-widget` 挂件**落的本地账本：

```
%USERPROFILE%\.dsh\.dshw-usage.json          ← 默认
<DSH_HOME>\.dshw-usage.json                  ← 设了 DSH_HOME 就在那
```

路径按「进程环境变量 `DSH_HOME` → 用户级注册表 `DSH_HOME` → `~\.dsh`」三级解析，
所以从资源管理器启动也能找到。本窗每 **3 秒**重读一次。

> 走这条路时 **DSH 没开余额就不会更新**，小窗会显示「本地 · N 小时前 · DSH 没开」。

### 两条路的差别

| | 联网 | 本地账本 |
|---|---|---|
| DSH 没开 | ✅ 照样更新 | ❌ 数字停在最后一次 |
| 需要 API key | 要 | 不要 |
| 「今日已用」 | ✅ 自己按余额变化累计 | ✅ 挂件算好的 |

所以**末行**会告诉你当前用的是哪条：`在线 · 12 秒前` 还是 `本地 · 3 分钟前`。

### 「今日已用」怎么自己算

余额接口只给余额、不给用量，所以自己推：**只累加余额的「减少」**，
充值 / 调账（余额变大）不冲抵。结果落在小窗目录的 `.balance-online.json`，
重启接着算，跨天自动归零。

- 当天第一次观测时，先把**本地账本已有的今日数**当起点接上，
  所以当天中途启动 / 重启不会把数字清零
- 窗口关着的那段时间，只要没充过值，下次开窗时的余额降幅也会被算进去
- 跨天（文件里的日期不是今天就）直接归零重算 —— 不会把隔夜用量算到今天头上
- 余额接口只返回**2 位小数**，所以自算值的最小粒度是 0.01 元；
  挂件是按键数×单价算的，两者可能差个几分钱以内（实测差 0.005）
- 每 60 秒采样一次，所以「用了一点又立刻充值」这种同分钟内抵消的情况可能漏掉
- 正在按 60 秒采样，所以窗口刚开的头几秒显示的是接上的旧值

鼠标停在「今日」那行能看到当前用的是哪种算法。

## 峰谷时段

- **高峰**：北京时间**周一至周五**（**不含法定节假日**）**9:00–12:00、14:00–18:00**
- **谷**：其余时段 —— 包括**周末、调休上班的周末、法定节假日全天**

和 `dsh-whale-widget` 的判定**完全同源**：时段表 `[[9,12],[14,18]]` +
2026 年法定节假日清单（33 条）逐条核对过。

> ⚠️ **节假日清单是硬编码的，只到 2026 年。** 每年 11 月国务院公布次年放假安排后，
> 要把新日期补进 `balance-window.ps1` 里的 `$HolidayValley`，否则次年假期会被误判成高峰。
> 只需列**放假**的日子 —— 调休上班日都落在周末，本来就按谷价算。
>
> 例：2026-10-07 是周三但属国庆假期，只看「周三 9-12 是高峰」会算错，
> 必须靠节假日清单才判得对。

鼠标停在「今日 / 峰谷」那行能看到这条规则。

### 倒计时

会多一行 `距高峰 18 时 22 分` / `距谷价 45 分`，告诉你还有多久切换。

- 算法与挂件的 `nextPeakChangeAt` **完全同源**：只扫北京时间 0/9/12/14/18 点这几个边界，
  往后找第一个状态不同的时刻；跳周末/假期会自动到下一个工作日
- 已用挂件原版算法交叉验证，**12 个抽查点全部一致**（如周六 10-10 会跳到周一 10-12 09:00）
- 一律按 **UTC+8** 算，本机时区不是北京也不会算错
- 右键 → **显示峰谷倒计时** 可以关掉

## 怎么启动

双击 `start-silent.vbs`（无黑框）。

首次如被 SmartScreen 拦，右键 `.ps1` → 属性 → 勾选「解除锁定」；或在 PowerShell 里对该目录执行一次：

```powershell
Unblock-File .\balance-window.ps1
```

## 怎么用

| 操作 | 效果 |
|---|---|
| 拖动 | 移动位置（自动记住）—— 抓方框或人物本身，空白处是穿过去的 |

| 鼠标停在金额上 | 显示「赠送 ¥x · 充值 ¥x」（联网模式才有） |

## 版式

- **方框只包文字**，所以方框很小（约 148 × 72 px）；人物不再把方框撑大
- 人物立在方框**左边**，两者**底边对齐**；人物比框高，头和上身就露在框外
- 人物往右压住方框左边 13 px，做出「人站在牌子前面」的层次
- 窗口比可见内容多留一圈**透明余量**（上方 12%、左右 6%），留给弹跳放大 10% 和摇摆 ±1°；
  不留的话动画到顶时头会被窗口切平。改形象大小时余量自动重算
- **默认置顶**。想让别的窗口能盖住它：右键 → 取消勾选 **窗口置顶**（会记住）。
- **方框和人物以外的透明区域点得过去**（窗口背景设为空），不会挡住后面的窗口、也不会误触拖动。
  要拖动请抓方框或人物本身

想调这几个数字：叠压量在 `$petHost.Margin`（`-13`，负得越多压得越进去）；
余量在 `Update-PetRoom` 的 `0.06`（左右）/ `0.12`（上方）。

## 形象

同目录下放一张 `pet.png`（也支持 `.jpg` / `.jpeg` / `.gif` / `.bmp`），就会用它当形象；
**没有图就回退到代码画的小鲸鱼**。想换形象：把你的图命名成 `pet.png` 丢进本目录，重启即生效。

右键 → **形象大小**：小 80 / 中 112 / 大 144 / 特大 190（px），只对图片形象有效。

## 待机动画与互动

**待机**（一直在动）：

- **呼吸式起伏**：以**脚底为轴心**竖向缩放 3%（144 px 的人 ≈ 头顶上下 4 px），周期 2.4 s
- **轻微摇摆**：±1.0°，周期 3.7 s（同样以脚底为轴心）
- 压扁的同时横向微胀 1.2%，看起来像「呼吸」而不是被压瘪

> **两只脚是钉在地上的，这是故意的。** 早期版本用「上下平移」做起伏，结果整个人
> 连着脚一起飘起来，看着像气球。改成绕脚底缩放后：脚不动、只有脚以上在动。
>
> 实测（逐帧量人物轮廓）：
> ```
> 头顶 y : 24→28→24   摆幅 4 px
> 脚底 y : 167 恒定    摆幅 0 px
> ```
>
> 想做回「脚也抬起来」的效果：把 `Start-Sway` 里的纵向缩放换回 `TranslateTransform` 平移即可。
> 轴心由 `$petHost.RenderTransformOrigin = (0.5, 1.0)` 决定，改 `1.0` 就能把轴心抬到腰部。

两个周期故意不成整数比，叠起来不会看出循环。
只用 `RenderTransform`（不参与布局），所以**窗口尺寸不会跟着抖**。

**互动**（有刺激才动）：

| 触发 | 反应 | 时长 |
|---|---|---|
| 鼠标移上去 | 拉伸到 1.06（站直一点，不抬脚） | 0.32 s |
| 点一下 | 1.00 → 0.90 → 1.10 → 0.96 → 1.00（原地弹，同样绕脚底） | 0.50 s |
| 余额变动 ≥ ¥0.05 | 左右拖 −4 / +4 / −2.5 / +2.5 / 0 | 0.56 s |

> 待机与互动走**两条不同的变换通道**（待机在外层、互动在内层），所以边浮边点不会互相抢动画。
> 点击判定：按下到抬起的拖动幅度小于 **3 px** 就算点击（容忍手抖），超过就是拖窗。

右键 → **待机动画与互动（晃动 / 弹跳）** 一键全关（待机 + 三个互动都听它的）。
觉得幅度不合适就改 `Start-Sway` 里的 `0.97` / `1.012` / `±1.0`，
或 `Invoke-Bounce` / `Invoke-Perk` / `Invoke-Shake` 里的关键帧。
